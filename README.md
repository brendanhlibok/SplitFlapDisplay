# SplitFlapDisplay

Firmware and control software for a 45-module split-flap display driven by an ESP32.

## Overview

This project drives a physical split-flap display (45 modules) from an ESP32 microcontroller, handling module control at the firmware level and exposing a way to set what's shown on the display.

## Setup

Hardware wiring and firmware build/flash instructions are still in progress and will be documented here.

## Control Interface

The display will be controllable through a web UI hosted by the ESP32, letting you set the displayed text from a browser on the same network. This is still under development.

## Status

Early stage — hardware and firmware are in active development.
